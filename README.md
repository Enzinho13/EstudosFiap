# Engenharia de Software - FIAP

Repositório dedicado ao armazenamento, organização e versionamento de todos os projetos, exercícios, aulas e atividades práticas desenvolvidos durante o bacharelado em **Engenharia de Software na FIAP**.

---

## Objetivo do Repositório

O intuito deste repositório é registrar minha evolução acadêmica e técnica, servindo como um portfólio prático de projetos e consolidando os conhecimentos adquiridos ao longo da graduação.

Aqui você encontrará:
- **Atividades das Disciplinas:** Exercícios práticos e laboratórios.
- **Python & Algoritmos:** Desenvolvimento da lógica de programação, sintaxe, estruturas de dados e automação.
- **Projetos FIAP:** Resoluções de desafios práticos, Challenge e projetos acadêmicos.
- **Foco Técnico:** Fundamentos de engenharia, arquitetura de software, desenvolvimento e cibersegurança.
